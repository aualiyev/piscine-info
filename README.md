## 🎯 Как устроен рейд

- Система **автоматически** делит студентов на группы по **3 человека**.
- В группы попадают только те, кто **зарегистрировался** на рейд. Без регистрации участвовать нельзя.
- После экзамена, в **пятницу в 18:00**, рейд открывается: видно состав команды и условия задачи.
- Проект выполняется **в группе, вместе**.
- **Команды меняются каждый рейд.**
- Нужно найти сокомандников и создать **чат команды** для общения.

## 👑 Что делать капитану

1. Создать репозиторий в **Gitea** с названием **`quad`**.
2. Добавить в репозиторий всех участников команды.
3. Загрузить в репозиторий код решения.
4. Создать чат команды и найти всех сокомандников.
5. **Обязательно написать ментору в личные сообщения с отчётом** ([формат ниже](#-отчёт-капитана-обязательно)).

> Если репозиторий не создан или в нём нет кода, система автоматически поставит **FAIL (ПРОВАЛ)**.

## 📨 Отчёт капитана (ОБЯЗАТЕЛЬНО)

> 🚨 **Капитан ОБЯЗАН написать ментору в ЛС с отчётом. Это обязательный пункт, пропускать его нельзя.**
>
> 🔔 **Сокомандники, напомните капитану об отчёте!** Не оставляйте это на последний момент.

Формат отчёта:

```text
- First Last name:
- Username:
- Создал репозиторий: да / нет
- Дал доступы участникам команды: да / нет
- Создал чат команды и нашёл всех сокомандников: да / нет
- Начали ознакомление с задачей: да / нет
```

---

## 🔑 Как дать доступ участникам

1. Откройте созданный репозиторий **`quad`**.
2. Перейдите в **Settings** (настройки).
3. Откройте вкладку **Collaborators**.
4. В строке поиска введите **корректный username** участника команды.
5. Добавьте его. Повторите для каждого участника.

## 🆘 Если кто-то не выходит на связь

Если **капитан** или **один из участников** команды не выходит на связь, обратитесь к **ментору** для решения ситуации.

## ✅ Требования к решению

- Код **запускается без фатальных ошибок**.
- Алгоритм **решает задачу так, как требуется в условии**.
- Учтены **крайние случаи**, например:
  - пустой аргумент;
  - отрицательное число;
  - и другие некорректные данные.
- Такие случаи ловятся через **условия**, а программа завершается через **`return`**.
- Приветствуется **«красивый» код**: понятные названия, аккуратное форматирование, отсутствие лишнего.

## 🛡 Защита

- Длительность: **30 минут = 1 команда**.
- Проходит **всей командой**, в полном составе.
- Время согласуется внутри команды, запись на слот через таблицу.

**Что будет на защите:**

- Вопросы о том, как написан код и **кто что делал**.
- Проверка, можете ли вы **сами написать** этот код.
- Часть кода будет **убрана**, и её нужно **написать заново руками**.
- Главное: код **запускается без фатальных ошибок**.

**Как подготовиться:**

- Можно разделить между собой, кто какой кусок кода сможет написать.
- При этом **каждый** понимает **весь** код, а не только свой участок.
- Если один человек написал всё, он **объясняет остальным**.

> Ментор: «Валить я не буду. Главное, чтобы код запускался без ошибок».

## 💡 Главное

- Не делайте бездумный копипаст из ChatGPT: **поймите код и логику**.
- Работайте **в команде**.
- Лучше решить простой Quad **самостоятельно** и объяснить решение, чем скопировать всё через ИИ и не суметь объяснить.
- Загружайте решение **заранее**.
- Капитан пишет ментору с отчётом, а сокомандники ему об этом напоминают.
